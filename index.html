BEFORE YOU START

실습을 시작하기 전에

개념 확인은 인터랙티브 자료에서,
데이터 처리와 모델 학습은 노트북에서 진행합니다.

Colab 노트북은 어떻게 실행하나요?

각 실습의 Colab에서 실행을 누르고 위쪽 셀부터 순서대로 실행하세요. 필요한 패키지 설치와 데이터 준비 단계가 노트북에 포함되어 있습니다.

CNN·ST-MEM 실습을 위한 GPU 설정

Colab의 런타임 메뉴에서 런타임 유형 변경을 열어 GPU를 선택하세요. 다운로드와 모델 학습에는 시간이 걸릴 수 있으니 셀의 진행 표시를 확인해 주세요.

분류 실습에서 예측하는 것은 무엇인가요?

30초 ECG 구간 안에 전문가가 V로 주석한 박동이 하나 이상 있는지 예측합니다. V가 없다는 정답이 모든 부정맥이 없다는 뜻은 아닙니다. 정답 주석은 입력 특징과 구분합니다.
