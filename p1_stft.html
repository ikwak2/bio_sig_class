질문 01 · 창 길이

긴 창을 사용하면 시간과 주파수 정보가 모두 더 선명해질까요?

설명 보기

긴 창은 더 오래 관찰하므로 가까운 주파수를 구분하는 데 유리합니다. 하지만 그 창 안에서 일어난 서로 다른 시점의 변화가 한 결과에 섞입니다. 「12 → 28 Hz 변화」에서 5초 부근을 짧은 창과 긴 창으로 비교해 보세요.

질문 02 · Zero-padding

0.25초 창에서 FFT 점 수를 4배로 늘리면 10 Hz와 12 Hz가 잘 구분될까요?

설명 보기

주파수 점들이 촘촘해지지만, 새로 관찰한 신호는 없습니다. 같은 넓은 봉우리를 더 자세히 그릴 뿐일 수 있습니다. 「10 + 12 Hz 혼합」에서 중심을 5초에 놓고, FFT 점 수만 바꾼 뒤 창 길이를 2초로 바꿔 비교해 보세요.

질문 03 · Hop

Hop을 줄이면 시간 열이 많아집니다. 한 창이 관찰하는 시간도 길어질까요?

설명 보기

한 창의 길이는 그대로입니다. 분석을 더 자주 반복하므로 인접 창이 더 많이 겹칩니다. 시간축의 표시는 촘촘해지지만, 창 길이가 만드는 시간·주파수 구분의 한계가 사라지지는 않습니다.

참고: 정의와 현재 설정

개념계산식읽는 방법
STFTXm[k] = Σ x[mH+n] w[n] e−j2πkn/NFFT합은 n = 0, …, N−1m번째 구간에 창 함수 w[n]을 곱한 뒤 각 주파수 성분을 계산합니다. 스펙트로그램은 그 크기를 시간 순서로 배열한 그림입니다.
표본화 주파수fs = 360 Hz1초에 360개의 값을 갖습니다. 이 시연은 총 10초, 3,600개 샘플을 사용합니다.
창 길이T = N / fs한 번의 주파수 분석에 쓰는 관측 시간입니다. N은 창 안의 실제 샘플 개수입니다.
Hop / 겹침Δt = H / fs
겹침률 = 1 − H/N		다음 창으로 이동하는 간격입니다. H가 작으면 창이 더 많이 겹치고, 스펙트로그램의 시간 열이 늘어납니다.
Hann 창w[n] = ½(1 − cos(2πn/N))구간 양끝의 가중치를 작게 하여 잘라낸 경계에서 생기는 주파수 누설을 완화합니다. 여기서는 주기형 Hann 창을 사용합니다.
FFT 격자 간격Δf = fs / NFFT계산된 주파수 점 사이의 간격입니다. 두 주파수를 실제로 구분하는 능력은 관측 시간과 창 모양에도 영향을 받습니다.
Zero-paddingNFFT ≥ N창을 곱한 N개 값 뒤에 0을 채웁니다. FFT 격자는 촘촘해지지만, 관측 시간과 원래 신호의 정보량은 그대로입니다.
dB 색과 높이A[k] = ck|X[k]| / Σw[n]
dB = 20 log10(A[k] / 1)ck = 2, DC·Nyquist는 1		기준 진폭 1 a.u.에 대한 스펙트럼 크기입니다. 모든 프레임을 −60~0 dB의 같은 범위로 표시합니다. 프레임별 최댓값으로 다시 맞추지 않습니다. 단위 Hz당 파워밀도(PSD)와는 다른 양입니다.
계산 기준과 노트북 연결

이 HTML의 신호는 설명을 위해 생성한 합성 신호입니다. ECG 모양의 예제도 실제 환자의 측정 자료가 아니며, 세로축의 a.u.는 임의 단위입니다.

  • 전체 창이 신호 안에 들어가는 프레임만 계산합니다. 양끝에 경계용 신호를 덧붙이지 않습니다. 각 시간 열은 중심 시각의 앞뒤로 hop/2만큼 표시하며, 표시할 열이 없는 양끝 부분은 회색으로 남습니다. 프레임 수는 floor((L−N)/H)+1, 중심 시각은 (mH+N/2)/fs입니다.
  • 위치 슬라이더와 파형의 드래그는 가장 가까운 실제 STFT 프레임을 선택합니다. 현재 스펙트럼과 강조된 스펙트로그램 열은 같은 계산 결과를 사용합니다.
  • 기본 FFT 점 수는 N 이상인 가장 작은 2의 거듭제곱입니다. 따라서 기본 설정도 N보다 큰 경우에는 0을 채웁니다. 「기본의 4배」는 그 FFT 점 수를 네 배로 늘립니다.
  • 01_signal_processing(1).ipynb의 「STFT 피쳐 그림」은 360 Hz ECG의 10초 구간, 0.25초/2초 창, 50% 겹침, FFT 128/1024를 비교합니다. 이 HTML은 해당 창 길이와 기본 FFT 크기를 따르되, 합성 신호·독립 hop·경계 padding 없음·고정 dB 기준을 사용합니다.
  • 01 노트북의 특징 추출 함수는 1초 창·0.25초 hop을 사용합니다. 03_ecg_cnn_augmentation_teaching(1).ipynb는 128 Hz, 2초 창·0.5초 hop·반사 경계 padding을 사용하므로 프레임 수와 가장자리 모습이 다를 수 있습니다.
